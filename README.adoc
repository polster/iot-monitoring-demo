= IoT Monitoring Demo
:toc:

== Introduction

=== What's this?

A demo project showing how to use Elastic Search and Kibana to monitor IoT data based on a simple use case.

=== Prerequisites

* Docker Desktop, Podman Desktop, or any other compatible container runtime
* Docker compose support
* Make
* Optional: direnv
* pre-commit

== Get started

* Clone this repository
* Install pre-commit hooks:
[source,bash]
----
pre-commit install
----
* Run below command to start the stack:
[source,bash]
----
make docker-infra-up
----
* Access the Elastic Search instance at http://localhost:9200
* Access the Kibana instance at http://localhost:5601
* Create a simple index template:
[source,bash]
----
make setup-index-template
----
* Ingest some data using the provided python script:
[source,bash]
----
python3 scripts/generate_test_messages.py --count 300 --ingest
----
* Create a data view for the index in Kibana:
[source,bash]
----
make kibana-data-view
----
